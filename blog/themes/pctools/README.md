# PCTools - Retro DOS Theme for Hugo

A Hugo theme that brings back the nostalgic look of 1990s DOS applications like PCTools and Norton Disk Doctor.

## Features

- Classic DOS blue background with cyan/white text
- ASCII box-drawing characters for borders
- Monospace font styling (VGA-like)
- Keyboard navigation support
- Retro UI elements and animations
- Responsive design

## Installation

1. Add the theme to your Hugo site:
```bash
cd your-hugo-site
git submodule add https://github.com/yourusername/pctools.git themes/pctools
```

2. Update your `hugo.toml`:
```toml
theme = "pctools"
```

See `hugo.toml` for available configuration options.
